# Dukascopy FX Cash Research Registry

This directory is the canonical research-memory index for studies run on the registered ten-pair **Dukascopy FX Cash** dataset.

Start with:

- `../DUKASCOPY_FX_CASH_RESEARCH_STANDARD.md` — methodology and completion contract;
- `DATASET_CONTRACT.md` — immutable dataset semantics and naming;
- `INDEX.md` — human-readable study history;
- `index.json` — machine-readable master index;
- `studies/` — normalized per-study manifests/results;
- `migration_candidates.json` — branch-resident historical work still requiring formal reconstruction.

Detailed strategy code, reports and large result tables remain in their strategy-specific branches/folders. Each registry entry freezes the exact Git commit and paths required to recover them.

No raw market data belongs here.
