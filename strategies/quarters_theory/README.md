# Quarters Theory Research

This strategy area tests whether the canonical 250-pip Quarters Theory lattice contains predictive information beyond ordinary 50- and 100-pip round-number behaviour.

It is intentionally separated from DTR and Asia Sweep. Shared loaders and research utilities may be reused, but hypotheses, manifests, results, claims and holdout governance remain independent.

## Current conclusion

The first Stage-1 GBP/USD test does **not** support a positive short-horizon Large Quarter Point effect:

- 6,843 eligible round-level crossings from 2015-2021;
- 1,373 canonical Large Quarter Point crossings;
- primary 60-minute canonical-minus-roundness-matched effect: **-0.78 pip**;
- year-stratified weekly-block 95% interval: **-2.58 to +1.20 pips**;
- adjusted +10/-10-pip first-passage odds ratio: **1.02**, 95% interval **0.89-1.17**.

This fails the current Gate 0 for positive distinctiveness on GBP/USD. It is not yet a universal rejection across all pairs or all multi-day formulations.
